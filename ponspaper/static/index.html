Backtest on recorded data

The live trader records every poll. Replay the recording to evolve a large population in seconds (fills at the first recorded snapshot after the latency, model pricing):

python -m ponspaper replay --population 200

When running on a server (e.g. Render), download the recording and replay it on your own PC: Download recording then python -m ponspaper replay pons_snapshots.jsonl.gz
